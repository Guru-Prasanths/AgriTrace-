Project Recap

THE NEED FOR AGRITRACE

⚠️ Existing Challenges
  • Multiple intermediaries can reduce direct buyer access.
  • Market prices are not always easy to compare.
  • Produce origin and handling details may be fragmented.
  • Agricultural information is spread across platforms.
🌱 AgriTrace Solution
  • Digital farmer-to-buyer marketplace with separate farmer and seller portals.
  • Transparent crop-price information and district-wise market comparison.
  • Government datasets, crop information, and blockchain-supported traceability.
  • QR-based verification where supported.
Farmer → AgriTrace Platform → Buyer  |  Price transparency • Digital marketplace • Traceability

Functional Architecture

AGRITRACE – SYSTEM WORKFLOW AND FUNCTIONAL ARCHITECTURE

Authentication

Farmer and Seller portals • email/password • Google authentication integration • role-based access

Listing

Crop name • images • quantity and unit • price and location • quality and availability

Marketplace

Browse • compare listings • submit requests or offers • connect with farmers

Orders

Track requests • manage status • coordinate interactions • record supported transaction details

Price discovery

Tamil Nadu datasets and official resources • tomato comparison across Salem, Madurai, Coimbatore, Erode

Traceability

Produce Batch → Digital Record → Blockchain Transaction → QR Verification → Traceability Information

AgriTrace Points

Eligible activities • completion rewards • configured daily eligibility • balance • transaction history

Accessibility

Simple navigation • responsive interface • readable text • language accessibility • voice assistance

Architecture: HTML5 | CSS3 | JavaScript → Node.js | Express.js → PostgreSQL | Solidity | Hardhat | MetaMask | ethers.js → Government Agricultural Datasets / External Data Sources
• Comparison fields: Minimum, maximum, modal price, market, date, unit. Tomato values shown in any implementation are illustrative placeholders only.
• Traceability boundary: supported records only, not a deployed production blockchain. QR verification where supported.
